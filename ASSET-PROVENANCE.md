# Asset provenance

All visible 3D models, topology, rig pivots, shape design, procedural materials and animations were authored in this workspace. No third-party model pack, raster concept image or generated concept image is substituted for a game asset. The original SVG journey-map illustrations are code assets.

The requested Zoro and Luffy meshes are original procedural fan-art depictions; no license to the underlying One Piece characters is claimed. There is no external character-model dependency.

Three.js 0.180.0: MIT. DOMPurify 3.4.17: MPL-2.0 OR Apache-2.0. Package license files are in licenses/. Other build dependencies and versions are recorded in package-lock.json. The existing DM Sans/Manrope interface loads Google Fonts CSS with system-font fallbacks; no font files are bundled here.
